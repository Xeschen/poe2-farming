# 세팅 열람 시각화 · 2026-09-23

기본 노출은 세팅을 식별하는 정보로 줄이고 설명과 근거는 필요할 때 연다. 개인 데이터 형식, 편집 입력, 거래소 검색 조건은 바꾸지 않는다. 작업은 로컬 구현이며 공개 사이트 반영은 별도 배포 단계다.

## 표시 방식

- 서판: 실제 아이템 이미지·이름·개수·우선순위, 지정한 옵션을 가로 카드로 표시한다. 접두/접미는 등록 속성 ID로 판별한다. 속성의 티어를 알 수 없는 상황에서 P1/S1 같은 표기를 만들어 넣지 않는다. 수치 최솟값은 ≥로 표시한다. 미확인 옵션과 명시적 제한 없음은 구분한다.
- 경로석: 지정한 등급·속성 수·타락 상태와 수치 범위·옵션만 표시한다. 0, 최솟값만, 최댓값만, 양쪽 범위를 구분한다. 등급 미확인에 1등급 이미지를 대신 사용하지 않는다. 모든 조건이 비었을 때만 전체 미확인 문구를 쓴다.
- 서판·경로석 카드는 전체 영역에서 거래소 검색창을 연다. 검색 안내는 우상단에 마우스를 올리거나 키보드로 포커스할 때 표시하며, 터치 환경에서는 항상 표시한다. 접두는 붉은 P, 접미는 푸른 S로 표시하고 접근 가능한 이름에는 접두·접미를 유지한다. 편집 미리보기에서는 거래소 검색을 열지 않는다.
- 아틀라스: 노드 이미지 아래 이름을 표시하고 가로로 배치한다. 작은 화면에서 줄바꿈한다. 설명 카드에서는 전체 선택지를 항상 펼쳐 표시하고 선택된 항목의 배경색과 굵은 글씨로 구분한다. 선택 내용을 위에 반복하거나 ‘이 세팅의 선택’ 문구를 붙이지 않는다. 기존 기록이 사전 선택지와 일치하지 않을 때만 별도로 선택 내용을 보존한다.
- 대가: 대안별 구분과 선택한 능력 수를 유지한다. 편집기와 같은 단계 순서로 3열·4행에 모든 능력을 배치한다. 기록된 능력은 금색 테두리·불빛·체크 표시로 강조하고 나머지는 흐리게 표시한다. 모든 능력의 이름·소속 대가·단계·효과를 설명 카드에서 확인할 수 있다. 대가의 사용 조건은 펼쳐 확인한다.
- 사용 조건·추가 우선순위·근거는 접힌 세부 영역에서 보존한다. 서판·경로석·아틀라스·대가의 주요 섹션은 처음에 펼쳐져 있다.

노드 아이콘은 실제 button이다. 마우스 올리기, 클릭, 키보드 포커스/Enter/Space, 모바일 탭으로 설명을 연다. 아래 화살표는 설명 카드로 포커스를 이동하고 Escape/닫기는 아이콘으로 돌려준다. 바깥을 누르면 닫힌다. 모바일은 화면 아래의 오버레이를 사용해 아이콘 열을 밀어내지 않는다. 아이콘에 접근 가능한 이름을 제공하며 이미지 자체의 중복 낭독은 생략한다. PoEDB 링크는 설명 안에서 연다.

## 열람 레이아웃

목차 위의 목록·격자 아이콘으로 기본형·컴팩트형을 선택한다. 글자 라벨 대신 아이콘의 툴팁과 접근성 이름을 제공한다. 기본형으로 시작하며 선택은 `poe2-farming:detail-layout` 브라우저 설정으로 기억한다. 파밍법 데이터와 JSON 백업은 바뀌지 않는다. 브라우저 저장이 막혀도 현재 화면에는 적용한다. 편집·미리보기·라이브러리에는 적용하지 않는다.

컴팩트형은 카드 여백과 이미지 크기를 줄인다. 본문에 900px 이상 공간이 있으면 서판·경로석을 2열로, 아틀라스·대가를 나란히 배치한다. 창 축소·확대·기기 회전에 따라 실제 본문 너비를 기준으로 다시 배치하며, 좁은 화면은 1열로 표시한다. 아이콘 버튼은 최소 44px 조작 영역을 유지한다.

목차는 두 레이아웃에서 동일하게 작동한다. 화면 너비가 1000px보다 넓으면 본문 오른쪽 아래에 고정하고, 그 이하에서는 우하단의 고정 목차 버튼으로 연다. 레이아웃 선택 아이콘은 목차 상자 바깥의 위쪽에 분리해서 배치한다. 목차에는 링크와 동작 버튼만 표시한다. 비교 목록이 아래에 표시되면 그 높이만큼 띄운다. 문서 상단·중간·끝에서 접근할 수 있고, 작은 화면의 목차는 선택·바깥 클릭·닫기·Escape로 닫힌다. 화면 높이가 낮으면 목차 내부를 스크롤한다.

레이아웃 전환은 내용을 다시 그리지 않으므로 접기 상태와 포커스를 유지한다. 정보나 확인 상태를 생략하지 않는다. `tests/detail-layout-browser.mjs`에서 1440/960/390/320px, 창 크기 변경, 높이가 낮은 화면, 저장 제한, 재방문, 데이터 분리, 목차·팝업·거래소 검색을 검증한다.

## 전체 조합용 리소스

현재 기본 파밍법의 사용 여부와 무관하게 PoEDB 한국어 목록에서 확보했다.

| 종류 | 연결 항목 |
|---|---:|
| 일반·고유 서판 | 17 |
| 경로석 | 1~16등급, 16 |
| 아틀라스 노드 | 사전에 등록된 전체 332 |
| 대가 능력 | 자도·도리아니·힐다 총 36 |
| 합계 | 401 |

중복 URL을 합친 WebP 파일은 185개, 961,196바이트다. 전체 아틀라스 이미지 확보가 편집기의 선택 노드 범위를 확장하는 것은 아니다. 선택 효과가 있는 기존 목록을 그대로 사용한다. 고유 서판도 현재 편집기에 없는 종류의 이미지까지 확보하되 게임 데이터 선택지를 임의로 추가하지 않는다.

- `src/image-assets.js`: PoEDB ID, 한국어 이름, 원문 페이지, 원본 이미지 URL, 로컬 경로, 확인 날짜, 파일 크기와 SHA-256.
- `assets/poedb/`: 중복 없는 원본 WebP와 저작권·출처 안내. 이미지 가공 없이 보관한다.
- `scripts/refresh-image-assets.mjs`: PoEDB 목록 페이지를 읽고 기존 명칭/ID와 대조한 뒤 전체 이미지를 다운로드한다. 이름이나 항목이 누락되면 실패한다. 검증을 통과한 목록만 매니페스트로 쓴다.
- `scripts/release-files.mjs`: 매니페스트에 등록된 파일만 공개 빌드에 포함한다. 빌드 및 사이트 실행 시 PoEDB 이미지 서버를 요청하지 않는다.

출처: [서판](https://poe2db.tw/kr/Tablet), [경로석](https://poe2db.tw/kr/Waystones), [아틀라스 패시브](https://poe2db.tw/kr/Atlas_passive_skill), [대가 능력](https://poe2db.tw/kr/Masters_of_the_Atlas). 게임 이미지의 권리는 Grinding Gear Games에 있다.

갱신할 때 `npm run refresh:images`를 수동 실행한다. Playwright 브라우저가 필요하며 기존 Edge를 쓰면 `BROWSER_PATH`를 지정한다. 조사용 HTML은 Git에서 제외된 `test-results/`에 저장한다. 일반 빌드·테스트는 외부 접속 없이 저장된 리소스를 사용한다.

## 검증

`tests/visual-setup.test.mjs`는 전체 사전의 이미지 연결·해시와 조건의 0/범위/미확인/제한 없음 구분을 검사한다. `tests/visual-setup-browser.mjs`는 공개 하위 경로에서 185개 이미지를 전부 디코딩하고 1265/960/390/320px에서 아이콘 설명, 실제 선택값, 키보드·터치, 거래소 버튼과 가로 넘침을 검사한다. 기존 개인 편집·백업·이전 형식·관리 모드 검증도 함께 실행한다.
