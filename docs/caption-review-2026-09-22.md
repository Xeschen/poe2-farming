## 남겨 둔 미확인 사항

### 아즈메리 금고 힐다 선택 화면 추가 확인 · 2026-09-22

[원본 영상 14:12](https://www.youtube.com/watch?v=Mi3d9GtgwkI&t=852s)의 힐다 화면을 정지해 파란색으로 활성화된 4개 아이콘과 포인트 0을 확인했다. 선택된 위치는 1단계 왼쪽, 3단계 왼쪽·가운데, 4단계 가운데다. 게임 화면의 열 순서가 PoEDB 목록 순서와 다르므로 위치만으로 이름을 붙이지 않고 [PoEDB 한국어 대가 페이지](https://poe2db.tw/kr/Masters_of_the_Atlas)의 아이콘과 효과를 대조했다.

| 영상 선택 위치 | PoEDB 아이콘 | 능력 |
|---|---|---|
| 1단계 왼쪽 | HildaKeystone1 | 교배철 |
| 3단계 왼쪽 | HildaKeystone9 | 치명적인 적응 |
| 3단계 가운데 | HildaKeystone7 | 혼백의 부름 |
| 4단계 가운데 | HildaKeystone12 | 점령한 영역 |

기존 자막 검토는 ‘네 개’라는 발언과 혼백의 부름 설명만 반영해 나머지 능력을 누락했다. 이번 화면 대조로 힐다를 4개 구성으로 보완하고 조합 미확인 문구를 제거했다. `fullSetupVerified`는 영상 구성 확인으로만 변경하며 전체 아틀라스 경로와 현재 패치 실전 유효성은 계속 미검증으로 둔다.

- 모든 자료를 현재 패치에서 직접 플레이한 것은 아니다. 영상 수익을 시간당 순이익으로 변환하지 않았다.
- 전체 아틀라스 연결 경로와 일부 대가의 완전한 구성은 미검증이다. 일부 선택만 확인한 상태를 완성 세팅으로 승격하지 않았다.
- 혈통 보조의 첫 진입·반복 진입 서판 조합은 여전히 부분 초안이다. 통달한 영토 검색은 고유 이름까지만 지정하므로 숲 속성을 거래소에서 확인해야 한다.
- TheMidTierGamer 영상의 50지도와 40지도 언급은 일치하지 않는다. 처치 방법만 보조 근거로 쓰고 수익 계산에는 채택하지 않았다.

## 파일·재생성·검증

`data/farming-methods.ko.json`에는 파밍법 6종을 유지한다. 기존 6종의 수정은 `data/library-review.ko.json`에, 추가 5종과 보조 출처는 `data/library-additions.ko.json`에 기록한다. `npm run refresh:library`는 원본 정비 → 추가 자료 병합 → 재검토 반영 순으로 `data/library.ko.json`을 만든다. 존재하지 않는 ID나 중복 재검토 ID는 오류다.

검토 파일의 `captionAudit`에는 자막 종류·언어·구간·세그먼트 수·SHA-256과 확인 범위를 기록했다. 전체 자막 파일은 로컬의 무시된 검토 폴더에만 두고 배포 데이터에 포함하지 않는다.

각 항목의 `evidenceReview`와 보조 영상 ID는 개인 복사·편집·JSON 백업에 보존된다. 화면은 **자막 대조 · 실전 미검증**으로 표시하며 날짜와 검토 범위를 안내한다. 기존 개인 수정본은 자동으로 덮어쓰지 않는다.

단위 테스트 59개 및 catalog 브라우저 스위트 통과: 재생성 일치, 공식 선택지, 출처·보조 영상·검토 범위의 JSON 왕복, 잘못된 출처 거부, 수정된 거래소 조건, 이전 개인 저장본 보존을 확인했다. 브라우저에서는 11종 상세·복사·편집 저장, 출처 보존, 검색·비교·공유·이전 저장 형식과 모바일 비교를 확인했다.
