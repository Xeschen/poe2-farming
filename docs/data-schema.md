# 데이터 계약 · 개인 백업 버전 6

앱은 파밍법 11종을 하나의 라이브러리로 제공한다. 방식 분류 필드는 없다. 홈·목록·상세·편집·비교가 같은 파밍법 모델을 사용한다. 콘텐츠와 목적은 별도 검색 조건이다.

## 기본 자료와 개인 자료

기본 파일은 data/library.ko.json이다. scripts/refresh-library.mjs는 추출 자료 6종, 추가 자료 5종, 자막 재검토를 병합한다. 출처 패치·타임스탬프·미확인 사항을 보존한다. 생성 입력에 제외된 전략을 남기지 않는다. 배포에는 library.ko.json과 glossary.ko.json만 포함하며 조사 입력 파일은 포함하지 않는다.

개인 백업은 {format: "poe2-farming-personal", schemaVersion: 6, records: [...]}이다. 저장소 키 poe2-farming.personal.v1은 기존 저장본을 찾기 위해 유지한다. 레코드는 id, originId, originVersion, createdAt, updatedAt, method, sources를 가진다. 기본 업데이트는 개인 세팅을 덮어쓰지 않으며 복사 버전 차이를 표시한다.

## 파밍법

method에는 이름·목적·콘텐츠·패치·설명, 서판·경로석·지도·아틀라스·대가, 준비물·진행 순서·중단 조건·주의점, 출처·수익 사례·미확인 사항·개인 메모를 저장한다. 경로석·지도·아틀라스·대가 객체는 필수이며 객체 내부의 null만 미확인을 뜻한다.

budget은 선택적 {amount, currency}이다. 금액은 지도 1회 기준이고 0과 null을 구분한다. 비용 기준 선택 필드는 없다. 영상의 정성적 투자 분류를 금액으로 환산하지 않는다.

tablets.usage는 use, not_used, unknown 중 하나다. not_used에는 서판 항목이 없어야 한다. 서판 개수는 null 또는 1~4, 경로석 등급은 null 또는 1~16, 속성 수는 null 또는 0~8이다. 서판의 이전 잔여 사용 횟수 값은 출처 보존용이며 편집·검색에 쓰지 않는다.

편집 화면에는 서판 사용 여부 선택을 제공하지 않는다. 새 개인 기록은 서판 없음(not_used)으로 시작하고, 서판 행을 추가하면 use, 마지막 행을 삭제하면 not_used로 반영한다. 기존 자료의 unknown은 구성 변경 없이 열거나 저장할 때 그대로 보존한다. 사용 여부 필드는 이전 백업과 자료의 미확인 상태를 보존하기 위해 내부 계약에 유지한다.

선택형 속성은 modifierId와 text, priority, metric, min, unit을 가진다. ID·문구·수치가 등록 카탈로그와 일치해야 한다. 서판 종류와 속성의 적합성, 중복 효과, 대가별 능력 소속 및 최대 4개를 검증한다. 기존 ID 없는 속성 문장은 개인 원문을 보존한다. 아틀라스는 선택 효과가 있는 44개 노드를 콘텐츠·지역 레벨과 가나다순으로 제공한다.

경로석 효과는 35개 통합 선택지를 제공하고 이전 수치별 ID도 읽는다. properties는 itemRarity, monsterRarity, packSize, monsterEffectiveness, waystoneDropChance, gold, experience, revives의 독립적인 {min,max} 조건이다. 생략·null은 제한 없음이며 0은 명시한 경계값이다. 최소≤최대, 0~100000을 검증하고 부활은 정수다. 실제 게임의 최대값을 뜻하지 않는다.

## 출처와 확인

주의점 constraints는 text, evidence와 선택적 sourceUrl을 가진다. sourceUrl은 댓글·문서 등 참고 자료의 HTTPS 주소다. 올바른 안내를 본문에 직접 반영하며 별도 corrections 필드와 정정 전 설명은 제공하지 않는다.

sources에는 영상 ID·제작자·제목·게시일·패치·언어·URL, 선택적으로 원제·조회수 확인 근거·검토 메모를 저장한다. method.creatorGuide는 연결 문서의 URL·구성·확인일·범위를 기록한다. evidenceReview는 자막 검토 날짜·범위·한계다. supportingVideoIds는 해당 레코드 sources에 존재해야 한다. 개인 복사·편집·백업에서도 이 정보와 타임스탬프를 보존한다.

자막 대조를 실전 검증으로 표시하지 않는다. 전체 아틀라스 연결 경로와 대가의 완전한 구성은 별도 확인 값이다. reportedResults의 영상 수익·비용·표본은 검증된 순이익으로 변환하지 않는다. 사전 용어는 고정 ID, 공식 한국어 이름, 분류, 설명, 선택 효과, PoEDB 한국어 URL과 확인 정보를 가진다.

## 이전 형식 정리

이전 corrections의 안내와 URL은 constraints의 text와 sourceUrl로 옮긴다. 개인 문구는 그대로 유지하고, 폐기된 설명을 가리키는 supersedes는 현재 안내의 근거로 사용하지 않는다. 기본 자료의 변경 이력은 조사 문서에 남긴다.

src/legacy.js는 이전 1~5 백업과 0.1.0/0.2.0 추출본을 현재 모델로 옮기는 단방향 변환이다. 폐기된 제작 기록은 저장·가져오기·내보내기 모두에서 제외한다. 남은 기록의 이전 kind와 budget.basis를 제거한다. 묶음 비용을 지도 1회 비용으로 오인하지 않도록 기존 금액은 메모에 보존하고 지도당 금액은 미확인으로 둔다.

정상 변환 및 검증을 마친 브라우저 저장본은 버전 6으로 갱신한다. 남은 개인 ID·복사 버전·생성일·수정일·메모·세팅·출처는 유지한다. 남은 항목에 오류가 있거나 쓰기에 실패하면 기존 저장 문자열을 지우지 않는다. 변환은 반복해도 같은 결과여야 한다. 새로운 버전 6에는 폐기된 필드·서판 재료 용도·빈 세팅 객체를 허용하지 않는다.

## 저장·복원·주소

가져오기는 2MB·200개 한도, 중첩 필드·숫자·HTTPS 주소·영상 ID와 시각 일치·중복 ID·고유명사를 검사한다. 동일 기록은 건너뛰고 같은 ID의 다른 내용은 별도 ID로 복원한다. 미래 버전·알 수 없는 필드는 거부한다. 저장 실패·손상·다른 탭의 변경 시 덮어쓰기를 막는다.

편집 초안은 저장본과 분리한다. 저장은 검증 후 반영하며 취소는 초안만 폐기한다. JSON 내보내기는 저장된 현재 형식의 records만 포함한다.

공유는 ?method=<기본 ID>, 비교는 ?compare=<기본 ID>를 2~3개 사용한다. 개인 ID·메모는 URL에 넣지 않는다. 목록은 ?view=library, 개인 목록은 ?view=library&scope=personal이다. 이전 분류 주소는 현재 목록으로 연결하고 더 이상 생성하지 않는다.

거래소 검색은 저장한 아이템 조건만 파생한다. 개인 정보·출처는 넣지 않고 검색 창의 임시 수치는 원본을 수정하지 않는다. 카카오 즉시 구입 주소와 고정 거래소 ID 연결은 docs/trade-search.md에 기록한다.

## 사용성 개선의 상태 구분

서판 항목의 선택적 optionRequirement는 unknown 또는 unrestricted이다. 생략은 unknown과 같으며 빈 options를 제한 없음으로 추론하지 않는다. unrestricted와 비어 있지 않은 options는 함께 저장할 수 없다. 옵션을 추가하면 조건 지정 상태로 전환한다. v5 백업을 v6으로 옮길 때 기존 빈 배열과 개인 메모의 의미는 바꾸지 않는다.

준비 체크와 현재 진행 단계는 세팅 내용과 분리된 탭 메모리다. 선택한 기록 ID와 세팅 전체의 서명에 연결하고 세팅이 바뀌면 초기화한다. 저장·백업·공유 URL에는 포함하지 않는다. 빠른 메모는 기존 method.notes이며 선택 문장을 복사해도 원문을 보존한다. 별도 초안 자동 저장은 지원하지 않는다.
