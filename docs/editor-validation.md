# 선택형 편집기 · 2026-09-21

요청한 8개 변경을 새 파밍법과 기존 개인 세팅 편집 화면에 적용했다. 패치·서판 속성·아틀라스·대가는 선택 목록을 사용하고 인원 조건 입력을 제거했다. 투자 비용은 수치·화폐·지도 1회 기준으로 표시하며 옛 영상의 높음/낮음 분류를 임의의 수치로 바꾸지 않는다. 목록형 필드는 항목 추가·삭제, 여러 줄 붙여넣기 분리로 입력한다. 지도 지역과 환경은 체크박스이며 미선택을 허용한다. 대가는 소속 능력과 효과를 단계별 카드로 선택한다.

## 자료

`src/editor-data.js`는 한국어 PoEDB의 [아틀라스 패시브](https://poe2db.tw/kr/Atlas_passive_skill), [대가](https://poe2db.tw/kr/Masters_of_the_Atlas), [환경](https://poe2db.tw/kr/Biome), [방사능 노출 서판](https://poe2db.tw/kr/Irradiated_Tablet) 및 7종의 서판별 속성 페이지에서 추출한 정적 스냅샷이다. 각 서판 속성에 출처 URL을 보존한다. 332개 아틀라스 명칭, 대가 능력 36개, 서판별 등록 속성 79개를 제공한다. 원문 수치가 비어 있는 속성은 선택 목록에서 제외했다. 미번역 효과는 추측 번역하지 않는다. 고유 서판의 비고정 속성 편집은 등록된 항목이 없음을 안내한다. 원본 파밍법 JSON은 변경하지 않았다.

기존 사전 ID를 유지하며 새 명칭을 추가했다. 아틀라스와 대가에 같은 이름이 있는 능력은 상세 카드에서 각각의 출처와 설명을 구분한다. 자료의 현재 패치 유효성, 전체 아틀라스 연결 및 대가의 실제 배분 가능 여부를 보증하지 않는다. 패치는 현재 원본 자료의 0.5·0.5.5와 이전 개인 기록에 저장된 버전이 선택 가능하다.

## 카탈로그 갱신

scripts/refresh-editor-catalog.mjs는 검토한 PoEDB HTML을 로컬에서 추출한다. 인수로 스냅샷 폴더를 전달하거나 test-results를 사용한다. 파일명은 poedb-Maps.html, poedb-Atlas_passive_skill.html, poedb-Masters_of_the_Atlas.html과 poedb-서판영문이름.html 형식이다. 서판 영문 이름은 스크립트의 8종 목록에 정의돼 있다. ## 그룹 단순화와 거래소 검색

서판 드롭다운의 구분 제목은 접두·접미만 유지한다. 각 구분 안에서 공통 옵션 뒤에 전용 옵션을 모으고 두 묶음 안에서는 가나다순으로 정렬한다. 개별 옵션의 전용 표시는 유지한다. 경로석 드롭다운은 저·중·고등급 표기를 제거하고 효과 및 수치 범위로 선택한다.

저장된 상세 화면에 경로석·서판별 거래소 검색 버튼을 추가했다. 조건과 리그를 선택한 뒤 생성한 주소를 복사하거나 새 탭으로 연다. 필수·권장·회피 조건을 기본 반영하며 미연결 조건은 표시한다. 기본 리그는 금단의 의식(Forbidden Rites, 0.5.5)이다. 데이터 형식 변경 없이 기존 저장본을 유지한다. 연결 범위·출처·공식 거래소 실검색 미검증 사유는 `docs/trade-search.md`를 참고한다.

단위 45개와 브라우저 7개 스위트 통과. 거래소 스위트는 `/dist/` 하위 경로에서도 통과했다. 실제 저장 후 주소의 압축을 풀어 조건을 검증했고 리그 변경·주소 복사·조건 선택·편집 후 새로고침·미연결 안내·기존 개인 데이터 불변을 확인했다. 데스크톱과 390px 모바일의 검색 창 캡처에서 줄바꿈·버튼·가로 넘침을 확인했다. 외부 거래소 결과는 보안 확인 화면 때문에 검증하지 못했다.

## 편집 목차·효과 통합·경로석 수치 검색

- 넓은 화면에서는 편집기 오른쪽에 고정 목차를, 좁은 화면에서는 상단 가로 목차를 제공한다. 기본 정보·서판·경로석·지도·아틀라스·대가·진행·출처·미리보기에 이동한다. URL이나 저장 상태를 변경하지 않으며 잘못된 입력 중에도 이동할 수 있다. 키보드로 누르면 해당 섹션에 포커스를 함께 옮긴다.
- 옵션의 등급 표기만 숨겼던 이전 구현을 수정했다. 수치 구간별 80개를 35개 주요 효과로 통합한다. 수치만 다른 효과는 하나로, 서로 다른 지대 효과는 별도 선택지로 유지한다. 기존 수치 기록의 읽기·백업을 유지하고 ‘옵션 수치 제한 해제’를 눌렀을 때만 통합 ID로 바꾼다.
- 경로석 자체의 아이템 희귀도·몬스터 희귀도·무리 규모·몬스터 효율·경로석 출현 확률·골드·경험치·부활을 최소/최대 범위로 저장한다. 상세·비교에 표시하고 검색 창에도 반영한다. 검색 창에서 바꾼 수치는 개인 세팅과 분리한다. 카카오 호스트와 한국어 아이템명으로 검색 주소를 생성한다.
- 단위 49개, 브라우저 8개 스위트 통과. 새 스위트는 1440px/390px, 목차 클릭·키보드 이동과 입력 보존, 중복 옵션 제거, 8종 수치의 저장·새로고침·검색 객체 대응, 최대<최소 오류와 정상본 보존, 검색 창 조정의 저장본 불변, 이전 수치 기록의 명시적 통합을 검증했다. `/dist/`에서도 새 스위트 통과. 관련 화면 캡처의 가로 넘침과 목차 위치를 확인했다.

카카오 화면은 회원·인증 페이지로 이동하는 과정에서 자동 승인 검토가 계정 세션 접근 위험을 이유로 차단했다. 이를 우회하지 않고 공개 코드·데이터로 필터와 주소를 확인했다. 실제 카카오 검색 결과 검증은 미완료이며 검색 창과 거래소 문서에 한계를 표시한다.

## 저장/취소와 경로석 입력 배치

경로석 등급(1~16), 속성 수(0~8), 타락 여부는 미확인을 포함한 드롭다운으로 한 줄에 표시한다. 수치 조건은 옵션 선택보다 위에 있으며 기본 접힘, 펼치면 2열이다. 행 추가로 편집기를 다시 그려도 펼침 상태와 스크롤을 보존한다. 위·아래에 저장/취소를 제공하고 미리보기는 별도 영역에 둔다.

기존 자동 저장 동작은 명시적 저장으로 교체했다. 입력 중 검증은 계속하지만 저장하기 전에는 records/localStorage를 바꾸지 않는다. 기존 세팅 취소는 편집 전 상태를 유지하고 새 항목·복사본 취소는 빈 개인 기록을 남기지 않는다. 저장 검증 오류·용량 실패·탭 충돌 시 편집을 유지하며 기존 records도 덮어쓰지 않는다. 기존 중간 저장본 검증 테스트는 실제 저장→재편집 체크포인트를 사용하도록 변경했다.
