# 3단계 데이터 확장·검색·비교

## 구현

현재 기본 파밍법 11종을 제공한다. 콘텐츠·서판 사용 방식과 미확인 수치를 구별하며 출처·제작자 정정·수익 사례를 보존한다. 화면 분류와 백업 구조의 최신 기준은 data-schema.md를 따른다.

콘텐츠·목적·서판·대가·패치·투자 수준·확인 상태를 검색어와 함께 적용한다. 필터를 바꿔도 비교 선택은 유지한다. 2~3개 비교표는 차이가 있는 행을 표시하고 같은 행을 숨길 수 있다. 몬스터 희귀도·아이템 희귀도·경로석 수량·경로석 출현 확률은 별도 행이다. 개인 데이터와 원본도 비교할 수 있다.

기본 전략별 주소와 2~3개 기본 전략의 비교 주소를 제공한다. 공유 주소에 개인 ID·메모를 넣지 않는다. 모르는 ID·중복 ID·허용 개수를 벗어난 비교 주소는 명확한 오류를 표시한다. 뒤로·앞으로 이동 및 새로고침을 지원하며 URL의 배포 하위 경로를 유지한다. 개인 자료를 다른 브라우저로 옮길 때는 JSON을 사용한다.

## 확인 방법

2026-09-21 검증 완료: 단위 테스트 28개 통과, 두 브라우저 테스트 스위트 모두 기본 경로와 `/dist/` 하위 경로에서 통과했다. 기존 개인 저장·복원 동작도 회귀 테스트를 통과했다.

- `node --test tests/model.test.mjs tests/catalog.test.mjs`: 기존 저장 보호에 더해 전체 11개 추출 변환, 버전 1 개인 데이터 이전, 복합 필터·검색, 비교 상한과 수치 분리, 차이 판정, 공유 주소 왕복 및 개인 정보 제외를 검증한다.
- `node tests/browser.mjs`: 첫 시제품의 저장·편집·입력 검증·백업·복원·터치·키보드 동작 회귀 검증.
- `node tests/catalog-browser.mjs`: 11개 상세→개인 복사→수정, 원본 메타데이터 보존, 필터 조합·빈 결과, 비교 선택 제한·유지·해제, 차이 표시, 공유 주소의 새로고침·브라우저 기록 이동, 버전 1 저장소 이전, 모바일 표 가로 스크롤을 검증한다.

브라우저 검증 환경은 Windows의 Microsoft Edge headless / Playwright이며, 1440px 데스크톱과 390px 터치 환경을 사용한다. 빌드 후 `APP_URL=http://127.0.0.1:4173/dist/`로 같은 기능을 검사해 하위 경로 호환성을 확인한다. 화면 캡처와 테스트 백업은 Git에서 제외한 `test-results/`에 둔다.

## 명칭과 근거

명칭 사전을 고정 ID와 개별 확인 정보를 가진 75개 항목으로 확장했다. 기존 조사에서 확인한 명칭을 보존하며 사용 중인 주요 노드의 효과 설명을 보강했다. 2026-09-21에 [아틀라스 패시브](https://poe2db.tw/kr/Atlas_passive_skill), [아틀라스 대가](https://poe2db.tw/kr/Masters_of_the_Atlas), [아즈메리 혼백](https://poe2db.tw/kr/Azmeri_Spirit), [의식](https://poe2db.tw/kr/Ritual), [베리시움 잔류물](https://poe2db.tw/kr/Verisium_Remnant) 및 연결된 아이템 페이지를 확인했다.

효과 요약은 전체 툴팁 전사가 아니다. 각 설명 카드에서 선택한 효과와 PoEDB 링크를 함께 확인할 수 있다. 페이지 적용 패치가 명시되지 않아 사전의 패치는 null이며 영상 세팅의 현재 패치 유효성과 전체 경로를 확인한 것으로 표시하지 않는다.

## 메인 페이지와 경로 탐색 추가

메인은 파밍 라이브러리와 내 데이터로 연결된다. 목록 주소는 `?view=library`, `?view=library&scope=personal`이다. 상세 경로는 홈 → 파밍 라이브러리 → 파밍법이며 개인 항목은 내 데이터 경로를 추가한다. 전체 카드 클릭, 키보드·모바일 이동을 지원한다. 이전 분류 주소는 현재 라이브러리로 연결한다.

2026-09-21 추가 검증: 단위 테스트 29개와 기존 두 브라우저 스위트 통과. `tests/navigation-browser.mjs`는 기본 경로와 빌드의 `/dist/` 경로에서 모두 통과했다. 메인·목록 화면, 새 탭·새로고침, 뒤로/앞으로 이동과 검색 복원, 키보드·터치 경로 이동, 잘못된 편집의 이동 차단, 유효한 개인 메모 유지, 390px 화면의 가로 넘침을 확인했다. 데스크톱과 모바일 메인 화면 캡처를 검토했다.
