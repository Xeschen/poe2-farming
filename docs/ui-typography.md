홈·라이브러리 카드에 기존 서판 구성 요약을 추가해 제목만 열지 않아도 개수를 비교할 수 있게 했다. 서판 사용 상태도 함께 표시한다. 대가의 역할은 구성 선택에 영향을 주므로 보조 색상의 작은 글자에서 본문보다 약간 작은 강조 문장으로 변경했다. 시작 전 확인·오류 안내는 대비를 유지한다.

`styles.css` 마지막 Information hierarchy 블록의 `--text-*` 변수가 기준이다. 긴 한국어 제목과 서판 구성은 어절 단위 줄바꿈을 우선한다. 모바일 편집기의 수치 조건 2열과 등급·속성 수·타락 여부 1행 배치는 유지한다. 비교표는 자체 가로 스크롤을 유지한다.
