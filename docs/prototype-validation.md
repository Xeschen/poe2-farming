# 첫 시제품 검증 기록

이 문서는 첫 시제품 당시의 기록이다. 이후 데이터 확장·검색·비교의 구현 및 검증은 `docs/catalog-validation.md`를 참조한다.

2026-09-21 · Windows / Node.js 22 이상 / Playwright + Microsoft Edge headless

## 완료 범위

- 서판 수집 파밍 기본 자료 1건의 목록·상세와 개인 자료 목록, 이름·목적·서판 검색
- 원본과 독립된 개인 복사와 직접 추가, 정상 입력 자동 저장, 새로고침 후 유지
- 서판·속성 행, 수치 분류, 경로석·지도 조건, 아틀라스·대가, 준비물·순서·중단 조건·메모, 영상 타임스탬프 편집과 미리보기
- 공식 명칭 자동완성, 마우스·키보드·터치 설명 카드, 선택 효과 강조, PoEDB 한국어 새 탭 링크
- JSON 내보내기, 검증 후 병합 복원, 충돌 보존, 0.1.0 추출본의 지원 전략 변환, 미래 형식 거부
- 원본 업데이트 감지, 손상된 저장소 원문 백업, 저장 용량 오류와 여러 탭 간 덮어쓰기 차단

## 실행한 검증

`node --test tests/model.test.mjs`: 15개 테스트 통과. 숫자 범위·필수 필드·URL·타임스탬프·공식 명칭·중복 ID·과대 파일·미래 버전·예상하지 않은 필드 검증, null/0/false 구분, 백업 왕복, 원본 불변성, 복원 충돌, 이전 추출본 변환, 손상 및 저장 실패를 확인했다.

`node tests/browser.mjs`: 실제 브라우저에서 복사→편집→새로고침→내보내기→빈 저장소에 복원 후 JSON 완전 일치를 확인했다. 잘못된 입력의 저장 차단, 행 추가와 미리보기, 원본 업데이트 후 개인 자료 유지, 손상 복구, HTML 입력의 문자 표시, 저장 용량 오류·여러 탭 충돌을 확인했다.

1440px 데스크톱과 390px 모바일에서 스크린샷을 확인했다. 키보드 포커스·아래쪽 화살표·Escape, 모바일 터치 설명 카드와 편집·미리보기, 가로 넘침 유무를 점검했다. 기본 경로와 빌드 결과의 `/dist/` 하위 경로에서 같은 브라우저 테스트를 실행했다.

## 데이터 확인

기존 추출 JSON은 수정하지 않았다. 추가 명칭 사전은 `data/glossary.ko.json`이다. 2026-09-21에 PoEDB의 [서판](https://poe2db.tw/kr/Tablet), [아틀라스 패시브](https://poe2db.tw/kr/Atlas_passive_skill), [아틀라스 대가](https://poe2db.tw/kr/Masters_of_the_Atlas), [화폐](https://poe2db.tw/kr/Currency_Exchange), [탐험](https://poe2db.tw/kr/Expedition) 페이지에서 관련 명칭을 확인했다. 산 숙련·바다 개발의 개별 영문 경로는 조회 도구에서 접근되지 않아 앱 설명 카드에는 확인 가능한 아틀라스 목록 페이지를 연결했다.

영상의 적용 패치와 현재 PoEDB 설명은 별도 정보다. PoEDB 페이지 적용 패치는 미표기이므로 사전의 패치는 null이다. 산 숙련의 지역 레벨·완료 조건은 설명 카드에 표시하지만 전체 아틀라스 연결 경로를 검증한 것으로 취급하지 않는다.

## 남은 범위와 제한

GitHub 저장소 연결·실제 Pages 게시, 다른 전략 연결·2~3개 비교·상세 조건 검색·기기 간 동기화·오프라인 설치는 후속 범위다. 실물 휴대폰과 Safari/Firefox, 스크린리더 전체 탐색은 아직 확인하지 않았다. 현재 패치 파밍 효율·전체 아틀라스 경로·실제 판매 순이익도 미검증이다.
