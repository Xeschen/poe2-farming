# 기본 라이브러리 정비 · 2026-09-21

2026-09-22에 영상 10편의 자막을 재검토해 전체 11종을 갱신했다. [자막 대조 기록](caption-review-2026-09-22.md)이 최신 기준이다. 재생성 시 `data/library-review.ko.json`의 정정 사항도 적용한다.

같은 날 배포용 데이터에서 별도 `corrections` 필드를 제거했다. 룬 잔류물 회피 안내는 진행 순서·주의점에 직접 반영하고 고정 댓글은 주의점의 출처 링크로 보존한다. 상세 정정 배너와 비교표 정정 행은 제공하지 않는다. 이전 개인 백업의 정정문·URL은 주의점으로 옮긴다. 조사 문서에 남긴 정정 기록은 변경 경위이며 배포용 안내와 구분한다.

추가 조사에서 5종을 병합해 현재 총 11종이다. 선별 기준, 영상·문서 확인 범위와 부분 초안은 [추가 조사 기록](library-expansion-2026-09-21.md)을 참고한다. 아래는 최초 6종 정비 당시의 기록이다.

앱의 현재 선택형 편집·거래소 검색 구조에 맞춰 6개 파밍법을 정비했다. 원본 추출 파일 `data/farming-methods.ko.json`에는 파밍법 6종을 유지한다. 앱은 정비본 `data/library.ko.json`(0.2.0)을 읽는다. 최신 패치로 파밍법을 재검증한 작업이 아니며 원본 패치, 영상 출처·시각, 제작자 정정, 수익 사례, 미확인 상태를 보존한다.

서판 조건은 총 23개를 등록 속성으로 전환했다. 원본에서 명시한 최소값과 우선순위는 유지한다. 수치가 없었던 옵션의 `min`은 null이며 카탈로그에 보이는 수치 범위를 임의의 검색 최소값으로 사용하지 않는다. 고유 서판의 효과 설명은 일반 속성 드롭다운에 억지로 연결하지 않는다.

아틀라스는 선택 가능한 노드 16개 기록을 현행 드롭다운 문구와 연결하고, 고정 효과 기록 6개를 근거 유형과 함께 `otherPriorities`에 보존했다. 명칭 사전의 기존 ID는 유지하면서 선택 문구·링크도 카탈로그와 동기화한다. 대군주의 영토의 재활성화 룬 수는 한국어 PoEDB에 숫자가 비어 있어 추정하지 않고 미확인 사항에 적었다.

예상 투자 비용은 모두 미확인(null)이다. 영상의 상대적 투자 분류나 일부 소모품만 포함한 과거 비용 사례를 현재 총투자 비용으로 환산하지 않는다. 대가의 부분 구성·전체 경로 미검증 상태도 그대로 유지한다.

## 재생성과 호환성

### 로컬 관리 편집 · 2026-09-22

`npm run admin`은 루프백 주소에서만 실행되는 관리 서버다. 기본 자료의 **원본 편집**으로 기존 편집기를 열고 **원본 저장**으로 저장한다. 기존 항목 편집을 지원하며 신규 기본 항목·출처 등록과 삭제는 별도 기능이다. 개인 복사본 저장과 JSON 백업에는 영향을 주지 않는다.

저장본은 `data/library-overrides.ko.json`의 ID별 전체 파밍법이며, 조사 파일을 직접 변경하지 않는다. 이 파일이 해당 항목에 대해 최종 우선권을 가진다. 해당 파밍법을 이후 재조사하는 경우 관리 수정본도 함께 검토해야 한다. 일반 로컬 조회·관리 조회는 기본 라이브러리와 관리 수정본을 합쳐 제공한다. `refresh:library`는 조사 자료를 재생성한 뒤 관리 수정본을 적용하고, `build`도 같은 수정본을 적용한다. 따라서 저장 직후 `library.ko.json` 자체가 변경되지 않아도 화면과 빌드에는 반영된다. 관리 수정 파일은 개인 백업이 아니므로 저장소에 함께 포함한다.

서버에서도 기존 데이터 검증을 수행하고 출처·영상 근거를 유지한다. 저장 파일은 임시 파일 작성 후 교체한다. 다른 탭·외부 파일 변경으로 읽은 버전이 달라지면 409로 차단하며 편집 내용을 화면에 남긴다. 세션 토큰·동일 Origin·Host를 검사하고, 관리 모드가 아니면 쓰기 API가 없다. 세션 토큰은 메모리에만 존재한다.

공개 배포는 `dist/`만 사용한다. 관리 모듈과 `LOCAL_ADMIN_START/END` 구간은 빌드 시 제거하며 서버 스크립트와 관리 수정 파일은 배포하지 않는다. 기존 개인 편집·백업 기능은 정적 사이트에서도 유지한다.

검증: 관리 저장·취소·새로고침, 개인 데이터 유지, 입력 오류와 탭 충돌, 잘못된 Origin/Host/토큰, 재생성 적용, 수정된 데이터의 빌드 포함과 관리 기능 제외를 자동 검사한다. 테스트는 임시 프로젝트를 사용하며 실제 라이브러리를 변경하지 않는다.

`npm run refresh:library`로 검토한 대응표를 적용해 정비본을 생성한다. `scripts/refresh-library.mjs`는 원본 문구와 등록 속성·선택지가 일치하지 않으면 실패하도록 하여 임의의 유사 문자열 매핑을 막는다. 카탈로그를 바꾼 뒤에도 대응표를 재검토하고 테스트해야 한다. `npm test` 및 `npm run build`로 검증·빌드한다.

개인 저장소나 이전 JSON을 자동 정비하지 않는다. 원본 ID는 유지하며 라이브러리 버전·내용 지문이 달라지므로 이전 개인 복사본에는 기본 자료 변경 안내가 나타난다. 기존 수정·출처는 그대로이고 사용자가 현재 기본 자료를 새로 복사할 수 있다. 원본 0.1.0과 정비본 0.2.0의 가져오기를 모두 지원한다.

거래소 검증은 생성된 검색 객체의 속성 ID·최소값·카카오 URL 연결까지다. 카카오 실제 검색 결과나 현재 호가는 재검증하지 않았다.
