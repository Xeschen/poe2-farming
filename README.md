# PoE2 파밍 가이드

파밍법을 조건별로 찾고 비교하며, 개인 세팅을 시각적으로 편집하는 한국어 웹앱 프로젝트입니다.

3단계 데이터 확장·검색·비교를 구현했습니다. 파밍법 11개를 검색·비교하고 개인 세팅을 보관할 수 있습니다. 공개 배포는 아직 하지 않았습니다.

## 확정한 방향

- GitHub Pages의 기본 주소로 제공하는 정적 웹앱. 별도 유료 서버·데이터베이스·도메인을 사용하지 않습니다.
- 노드, 아이템, 스킬 등의 고유명사는 PoEDB 한국어 표기를 사용합니다.
- 용어에 밑줄을 표시하고, 마우스 또는 키보드 포커스로 설명을 보여줍니다. 클릭하면 PoEDB 한국어 페이지를 새 탭으로 엽니다.
- 모바일에서는 용어를 눌러 설명을 열고 카드 안의 링크로 PoEDB에 이동합니다.
- 입력 폼으로 파밍 데이터를 편집하고, 개인 수정본을 브라우저에 저장합니다.
- JSON 가져오기·내보내기로 백업·복원합니다. 개인 데이터는 자동으로 외부에 전송하지 않습니다.

## 현재 자료

- `data/library.ko.json`: 앱에서 사용하는 선택형 라이브러리 0.2.0. 파밍법 11개
- `data/library-additions.ko.json`: 자막·제작자 문서를 대조한 추가 5종과 보조 영상 출처. 조회수·확인 날짜·추출 한계를 보존하며 `refresh:library`에서 병합
- `data/library-review.ko.json`: 기존 자료의 자막 재검토 정정과 영상 10편의 확인 기록. 원본을 유지하며 재생성 마지막 단계에 반영
- `docs/caption-review-2026-09-22.md`: 현재 11종 자막 대조 결과·수정 내역·남은 미확인 사항
- `data/farming-methods.ko.json`: 영상 5개의 원본 추출본 0.1.0. 파밍법 6종의 문장·근거
- `docs/library-maintenance.md`: 항목별 정비 내역, 근거, 재생성 및 검증 방법
- `docs/research.md`: 영상 타임스탬프, PoEDB 명칭 근거, 추출 한계
- `docs/product-plan.md`: 화면, 저장 방식, 구현 순서와 완료 기준
- [사용성·UI 개선 요구사항](docs/usability-improvement-requirements-2026-09-22.md): 파밍 실행·화면 구성·유튜브 개인 정리 평가, 우선순위, 완료 기준과 후속 구현 인수인계
- [구현 후 사용성 재점검](docs/usability-recheck-2026-09-22.md): 현재 버전에서 확인한 개선, 상세 진입 위치 오류, 남은 준비·비교·메모 UI 개선과 검증 범위

현재 11종은 출처 영상 10편의 자막을 재검토했습니다. 미확인 항목과 이전 패치 자료가 있으며 현재 패치에서 직접 플레이한 검증 결과가 아닙니다. 수익 사례는 검증된 순이익과 구분합니다.

## 로컬 실행

Node.js 22 이상에서 별도 패키지 설치 없이 실행합니다.

```sh
npm start
# 또는 node scripts/serve.mjs
```

브라우저에서 http://127.0.0.1:4173/ 에 접속하세요. HTML을 파일로 직접 열면 JSON을 가져올 수 없으므로 로컬 HTTP 서버가 필요합니다. 공개 호스팅에서는 별도 서버 코드 없이 정적 파일만 사용합니다.

## 사용법

기본 라이브러리를 수정할 때는 기존 서버를 종료한 뒤 `npm run admin`으로 실행하세요. 같은 로컬 주소의 상단에 **로컬 관리 모드**, 기본 자료 상세에 **원본 편집**이 표시됩니다. 기존 편집 화면에서 **원본 저장**을 누르면 프로젝트 파일에 반영됩니다. 취소는 파일을 변경하지 않으며 개인 세팅도 그대로 유지됩니다. `npm start`는 관리 기능 없는 조회용 서버입니다.

관리 수정은 `data/library-overrides.ko.json`에 저장됩니다. 이 파일을 Git에 함께 포함하세요. 로컬 조회, `npm run refresh:library`, `npm run build`가 모두 수정 사항을 적용합니다. 공개 배포에는 **`dist/`만** 사용하며, 빌드 결과에서는 관리 모듈·관리 초기화 코드·수정 원본 파일을 제외하고 수정이 반영된 라이브러리만 제공합니다. 로컬 저장 자체는 공개 사이트를 갱신하지 않습니다.

첫 화면에서 **파밍 라이브러리**, **내 데이터**로 이동할 수 있습니다. 상단 로고와 **홈**은 메인 페이지로, **파밍 라이브러리**는 전체 목록으로 연결됩니다. 상세 화면의 경로에서도 라이브러리와 홈를 클릭해 이동할 수 있습니다. 목록 주소는 새로고침이나 새 탭에서도 유지됩니다.

새 파밍법과 개인 세팅은 선택형 편집기를 사용합니다. 적용 패치·서판 명칭·서판 속성·아틀라스 노드·대가는 드롭다운으로, 지도 지역·환경·대가 능력은 체크박스로 선택합니다. 비용은 금액·화폐·1회 기준으로 기록합니다. 목적·준비물·진행 순서는 항목별 추가·삭제가 가능하고, 여러 줄을 붙여 넣으면 항목으로 나뉩니다. 경로석은 최대 16등급, 속성은 최대 8개입니다. 패치 목록은 현재 자료에서 확인한 버전과 기존 개인 기록의 버전을 제공합니다.

콘텐츠도 체크박스로 선택합니다. 서판 개수는 1~4이며 잔여 사용 횟수는 입력하지 않습니다. 서판 속성 목록은 접두·접미별로 나누고 공통·해당 서판 전용 여부를 표시합니다. 지도는 PoEDB 엔드게임 목록 173개 항목의 이름을 통합한 159개를 검색·선택할 수 있습니다. 미사용 표시 항목도 포함하며 현재 리그 출현 여부는 미확인입니다. 아틀라스는 선택 효과가 있는 44개 노드를 가나다순으로 표시하고 선택 효과를 별도로 지정합니다. 이전 고정 노드 기록은 접힌 영역에 보존합니다. 대가 구성마다 5개 이상 능력을 고르면 오류를 표시하고 마지막 정상 저장본을 유지합니다.

개인 상세·편집 화면의 **개인 파밍법 삭제**를 누르면 확인 후 해당 기록을 삭제합니다. 취소하거나 저장에 실패하면 기록을 유지합니다. 삭제는 기본 자료에 영향을 주지 않습니다. 복원이 필요하면 삭제 전에 JSON을 내보내세요.

서판 속성은 **접두·접미** 두 구분 안에서 **공통 → 전용**으로 모으고 각각 가나다순으로 정렬합니다. 전용 여부는 옵션에 표시하며 별도 그룹을 만들지 않습니다. 경로석 옵션은 PoEDB의 수치 구간별 80개 항목을 **35개 효과**로 합쳤습니다. 같은 효과는 수치·등급과 무관하게 한 번만 표시하며 서로 다른 지대 효과는 유지합니다. 이전에 저장한 수치 범위는 보존하고 **옵션 수치 제한 해제**로 통합 효과로 전환할 수 있습니다. 아틀라스 노드는 콘텐츠별로 묶고 일반 아틀라스는 지도 70·75레벨 이상과 레벨 조건 미표기로 구분합니다. 대가·서판·노드·준비물 등 추가·삭제 시 현재 스크롤 위치와 펼친 근거 영역을 유지합니다.

세팅 편집 오른쪽의 **편집 목차**로 각 항목에 이동합니다. 작은 화면에서는 상단 가로 목차로 바뀝니다. 클릭·키보드로 이동해도 입력 내용과 저장 상태를 유지합니다.

경로석 등급·속성 수·타락 여부는 한 줄의 드롭다운입니다. 옵션 선택 위의 **경로석 수치 조건**은 접고 펼칠 수 있는 2열 입력입니다. 경로석의 **아이템 희귀도·몬스터 희귀도·무리 규모·몬스터 효율·경로석 출현 확률·골드·경험치·부활**을 최소·최대로 저장할 수 있습니다. 빈칸은 제한 없음이며 최소가 최대보다 크면 저장을 차단합니다. 세팅을 저장하고 상세로 돌아오면 각 서판과 경로석의 **거래소 검색**으로 조건을 확인하고 **카카오 거래소의 즉시 구입** 주소를 열거나 복사합니다. 검색 팝업 바깥을 누르면 닫힙니다. 기본 리그는 금단의 의식(Forbidden Rites, 0.5.5)이며 변경할 수 있습니다. 검색 창에서 수치를 조정해도 저장한 세팅은 바뀌지 않습니다. 미연결 옵션은 제외 사실을 표시합니다. 실제 거래소 결과는 미검증입니다. 연결 범위와 근거는 [거래소 검색 문서](docs/trade-search.md)에 있습니다.

목록의 **조건으로 좁히기**에서 콘텐츠·목적·서판·대가·패치·투자 수준·확인 상태를 함께 선택할 수 있습니다. 검색어도 동시에 적용됩니다. 미확인과 사용하지 않음·적용하지 않음은 서로 다른 조건입니다.

각 항목의 **비교에 담기**로 2~3개를 선택하고 하단의 비교 버튼을 누르세요. 준비 조건·서판 속성·경로석·아틀라스·대가·주의점을 나란히 볼 수 있으며 **차이만 보기**를 지원합니다. 개인 세팅과 기본 자료도 비교할 수 있습니다. 작은 화면에서는 각 비교 항목 아래에 파밍법 이름과 값을 세로로 묶습니다. 요약에서는 대안·주의점·출처 설명을 펼쳐 확인할 수 있습니다.

기본 자료의 **주소 공유**와 **비교 주소 공유**는 해당 항목으로 바로 열리는 URL을 복사합니다. 로컬 주소는 같은 컴퓨터에서만 사용할 수 있고, 공개 주소는 배포 후 사용할 수 있습니다. 개인 수정본은 URL에 포함하지 않습니다.

1. 기본 자료의 **내 데이터로 복사**를 누르거나 **새 파밍법**으로 시작합니다.
2. 서판·속성·경로석·지도 환경·아틀라스·대가·진행 순서를 편집합니다. 환경은 도시 세부 분류(바알·에조미어·파리둔)를 포함한 12종을 선택할 수 있습니다. 숫자 빈칸은 `null`(미확인)입니다. 기존 영상 출처·근거·타임스탬프는 편집 입력 없이 보존되며 상세 조회와 JSON 백업에 남습니다.
3. 하단 중앙 또는 편집 목차의 **저장**을 누르면 검증을 거쳐 개인 저장본에 반영합니다. **취소**는 이번 편집의 모든 변경을 버리고 기존 세팅으로 돌아갑니다. 새 파밍법·복사본도 저장 전에는 목록에 추가되지 않습니다. 입력 오류나 저장 실패 시 기존 저장본과 편집 중 입력을 유지합니다.
4. JSON 내보내기로 개인 자료를 백업하세요. 가져오기는 검증 결과 확인 후 복원하며, 같은 ID의 다른 내용은 별도 복사본으로 보존합니다.

밑줄 용어는 마우스·키보드 포커스로 설명을 표시합니다. Enter/클릭은 PoEDB를 새 탭으로 엽니다. 아래쪽 화살표로 설명 카드에 이동하고 Escape로 닫습니다. 터치에서는 설명 카드를 열고 카드 안의 링크로 이동합니다.

저장은 브라우저와 사이트 주소별로 독립적이며 저장소의 JSON 파일을 갱신하지 않습니다. 다른 포트·주소·기기에는 JSON으로 옮겨야 합니다. 브라우저 데이터 삭제 전 백업하세요. 저장 실패·손상·다른 탭 변경 시 안내를 표시하고 자동 덮어쓰기를 차단합니다.

개인 백업은 버전 6입니다. 이전 버전 1~5를 불러오면 폐기된 분류와 기록을 제거하고 현재 형식으로 저장합니다. 별도 정정 필드는 없으며, 이전 정정문과 출처 링크는 주의점으로 옮깁니다. 나머지 개인 세팅·출처·메모는 유지합니다.

## 검증과 빌드

열람 화면은 서판·경로석을 이미지와 지정 조건으로, 아틀라스·대가는 선택한 노드의 아이콘으로 표시합니다. 아이콘의 설명은 마우스 올리기·키보드 포커스·탭으로 열며 Escape나 닫기 버튼으로 닫습니다. 전체 조합을 위한 로컬 이미지 목록과 갱신 방법은 [세팅 시각화 문서](docs/visual-loadouts.md)에 있습니다.

일반 로컬 실행에는 패키지 설치가 필요하지 않습니다. 아래 개발 의존성은 브라우저 검증용입니다.

```sh
npm ci --ignore-scripts
npx playwright install chromium
npm test
npm run build
npm run check:release
npm run test:browser
```

- GitHub Actions와 첫 공개·업데이트·되돌리기 절차: [배포 문서](docs/deployment.md). 기본 설정은 업로드 시 검증만 수행하며 수동 배포를 선택해야 공개합니다.
- `test:browser`는 별도 임시 서버의 `/poe2-farming/` 경로에서 공개 빌드와 핵심 사용자 흐름을 검증합니다. 로컬 관리 기능도 임시 프로젝트에서 확인합니다.
- 배포 경계 및 이전 빌드 파일 제거 검사: `tests/release.test.mjs`. 공개 하위 경로·관리 기능 제외·새 브라우저 백업 복원: `tests/release-browser.mjs`.
- 데이터 계약·검증·백업 왕복·이전 추출본 변환·원본 분리·저장 실패 보호 테스트: `tests/model.test.mjs`
- 이전 기록 제거·버전 6 저장·가져오기·내보내기·반복 변환 검사: `tests/migration.test.mjs`, `tests/migration-browser.mjs`
- 브라우저 통합 테스트: `tests/browser.mjs` (실행 중인 로컬 서버와 별도 Playwright 환경 필요)
- 전체 전략·필터·비교·공유·이전 저장 형식 브라우저 테스트: `tests/catalog-browser.mjs`

## 사용성 개선 · 2026-09-22

상세·비교·작성은 본문을 우선한다. 다른 파밍법은 뒤로 가기나 상단 파밍 라이브러리를 통해 검색한다. ‘파밍법 바꾸기’ 버튼과 전용 팝업 목록은 제거했으며, 라이브러리의 검색·필터와 단일 결과 목록을 사용한다. 비교는 요약으로 시작하며 상세 조건을 펼칠 수 있다. 준비·진행 화면의 체크·단계는 이 탭에서만 유지된다. 각 서판의 핵심 옵션을 바로 표시하며, 중복 준비물 원문은 구성 설명으로 연결한다. ‘다음 판 다시 확인’을 지정한 준비만 다음 판에서 체크 해제하고, 다음 판 시작 단계도 선택할 수 있다.

편집 상단 빠른 메모, 문장 선택 후 복사, 드롭다운 검색, 항목 순서 변경, 작성한 항목 우선 모달 미리보기를 제공한다. 빠른 메모·준비/진행 미리보기와 전체 세팅 보기를 전환할 수 있다. 저장·취소 정책과 기존 영상 근거 보존은 유지한다. 미확인 서판 옵션과 명시적 제한 없음을 구분한다.
