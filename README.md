# PoE2 파밍 가이드

파밍법을 조건별로 찾고 비교하며, 개인 세팅을 시각적으로 편집하는 한국어 웹앱 프로젝트입니다.

현재 단계는 프로젝트 준비입니다. 웹앱 구현과 공개 배포는 아직 하지 않았습니다.

## 확정한 방향

- GitHub Pages의 기본 주소로 제공하는 정적 웹앱. 별도 유료 서버·데이터베이스·도메인을 사용하지 않습니다.
- 노드, 아이템, 스킬 등의 고유명사는 PoEDB 한국어 표기를 사용합니다.
- 용어에 밑줄을 표시하고, 마우스 또는 키보드 포커스로 설명을 보여줍니다. 클릭하면 PoEDB 한국어 페이지를 새 탭으로 엽니다.
- 모바일에서는 용어를 눌러 설명을 열고 카드 안의 링크로 PoEDB에 이동합니다.
- 입력 폼으로 파밍 데이터를 편집하고, 개인 수정본을 브라우저에 저장합니다.
- JSON 가져오기·내보내기로 백업·복원합니다. 개인 데이터는 자동으로 외부에 전송하지 않습니다.

## 현재 자료

- `data/farming-methods.ko.json`: 영상 5개에서 추출한 지도 파밍 6개와 제작·판매 1개
- `docs/research.md`: 영상 타임스탬프, PoEDB 명칭 근거, 추출 한계
- `docs/product-plan.md`: 화면, 저장 방식, 구현 순서와 완료 기준

초기 자료는 1차 추출본입니다. 미확인 항목과 이전 패치 자료가 있으며 현재 패치에서 직접 플레이한 검증 결과가 아닙니다. 수익 사례는 검증된 순이익과 구분합니다.

## 다음 구현 단위

서판 수집 파밍 하나로 조회 → 용어 확인 → 내 데이터로 복사 → 편집 → 새로고침 후 유지 → JSON 백업·복원의 흐름을 완성합니다.

개발 도구와 실행 명령은 앱 구현 시 추가합니다.
